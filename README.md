# IntentBot

IntentBot is a simple conversational chatbot built using **Rasa** and **Jupyter Notebook** to explore the fundamentals of natural language understanding (NLU) and intent classification.

The project was created as a learning exercise to understand how conversational AI systems process user input, classify intents, and generate appropriate responses. 

## Features
* Greeting recognition (e.g., "Hi", "Hello")
* Basic intent classification
* Simple entity extraction from user input
* Responds to structured requests such as:

  * **User:** "I need a top-up of 50 rupees."
  * **Bot:** "Customer requested a top-up of 50 rupees."

## Technologies Used
* Python
* Rasa
* Jupyter Notebook
